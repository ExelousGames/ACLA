## Definition

A driving error that costs time relative to the expert reference for
the same segment of track. Specific sub-labels (a late brake, a tight
entry, an over-high peak brake pressure, and so on) describe the
*kind* of mistake.

## Solution

Find the earliest technical mistake in the corner phase and fix that root cause first. Use the specific sub-labels to choose one concrete change, such as braking earlier, turning later, using less peak brake, or applying throttle more progressively.
